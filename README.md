# Emotion-Based Music Recommender

A Python and Streamlit project that detects the user's emotion from text and recommends Hindi songs based on their mood.

## Features

- Happy emotion detection
- Sad emotion detection
- Angry emotion detection
- Relaxed emotion detection
- Hindi song recommendations
- Select the number of recommended songs
- Simple Streamlit web interface

## Technologies Used

- Python
- Streamlit
